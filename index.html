# Rclone Google Drive — Personal Project This website describes a personal project used to connect rclone to Google Drive on a privately managed Linux NAS. The application is intended exclusively for personal use by its owner. It is not a public service and is not offered to third parties. ## Purpose Rclone is used to access and manage the owner's Google Drive files from a private Linux server. ## Contact For questions about this project, contact: carlodiianni77@gmail.com ## Privacy Read the [Privacy Policy](privacy.html) for information about the purpose and scope of this project.
