# Privacy Policy — Rclone Google Drive This project is a personal configuration used by its owner to access their own Google Drive files through rclone on a privately managed Linux NAS. ## Data access The application requests Google Drive access to allow the owner to list, read, upload, modify, and manage files according to the permissions granted to rclone. ## Use of information The application is intended for the owner's personal file management and synchronization. ## Data sharing This project does not operate a public service and does not intentionally share users' data with third parties. ## Security and revocation Access can be revoked through the Google Account security settings. Local copies and backups are managed by the owner on their own devices. ## Contact For questions about this project, contact: carlodiianni77-coder@users.noreply.github.com
